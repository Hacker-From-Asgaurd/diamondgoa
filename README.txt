# HH Goa 2026 – Builder Identity Generator

A fast, mobile-friendly web tool created for the Hacker House Goa 2026 hackathon.

Create a personalized HH Goa 2026 photo frame / builder ID, download it, and share it on X using #FrameInGoa.

## ✨ Features

- Upload your photo
- Create an HH Goa 2026 themed frame
- Generate a personalized Builder ID
- Add your name, role, and tech stack
- Download the generated image
- Share your identity on X
- Responsive and mobile-friendly
- No login required

## 🛠️ Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- HTML Canvas / Image Generation
- Framer Motion
